ShinyForge User Guide

Your all-in-one companion for shiny hunting, recording, collection tracking and save management on the Nintendo Switch and Nintendo 3DS.

Version 1.0 · For Windows 10 / 11, macOS 13+ (Apple silicon and Intel) and Linux (x64) · github.com/Domsanna/ShinyForge

1 Welcome

Welcome! ShinyForge puts all the tools a Pokémon collector uses into one friendly window. Pick your console, pick your game, and everything for that game is on one page.

✨ Automatic shiny hunting

Soft resets, wild encounters and fishing on the Switch and 3DS. It stops the moment a shiny (or anything you asked for) appears.

🎥 Recording & clips

Gap-free recordings split into numbered files, plus an automatic clip of every shiny.

📋 Pokédex tracker

Updates your Excel Pokédex spreadsheet from your save, and has a Pokédex window with each game's own sprites.

💾 Saves & Game Info

Exports every Pokémon from a save into a folder ready for Pokémon HOME tools, with a readable Game Info report.

🧬 Living Dex planner

Combines all your saves and shows which species you own, where, and what's still missing.

📈 Statistics & alerts

Odds, encounter rate and time estimates, plus phone and Discord alerts, a stream overlay and a phone remote.

Good to knowNothing risky happens unless you turn it on. Shiny RNG manipulation and auto-catch are off until you switch them on yourself. ShinyForge never changes your save files: it reads copies and makes backups before touching a spreadsheet.

ShinyForge comes in two versions. Both have the same features. The only difference is where your settings and data are kept.

Installer

  1. Download ShinyForge-Setup.exe from the Releases page. It's a single file.
  2. Double-click ShinyForge-Setup.exe. If Windows SmartScreen shows "Windows protected your PC", click More info → Run anyway. This happens because the program isn't code-signed.
  3. Follow the wizard. You can add a desktop shortcut.
  4. Leave Download the Pokédex tracker spreadsheets ticked to get the trackers during the installation. Only the ones you don't have yet are downloaded (about 2.2 GB for all of them), and each is checked against its published checksum. You can untick it, or cancel the download, and get a game's tracker later from inside ShinyForge.
  5. ShinyForge, this guide and your spreadsheet folder are added to the Start menu.
Your spreadsheets are safeThe installer only copies a spreadsheet if it isn't already there, so reinstalling or updating never overwrites your progress. Uninstalling keeps your spreadsheets and Backup Tools folder.

Portable

  1. Unzip ShinyForge-Portable.zip anywhere, or copy the whole ShinyForge Portable folder.
  2. Run ShinyForge.exe. The portable.flag file tells it to keep everything inside its own folder.
  3. To move to another PC, copy the whole folder. Your settings, hunt logs and backups go with it.

macOS

  1. Download ShinyForge-macOS-arm64.zip for an Apple silicon Mac (M1 and newer), or ShinyForge-macOS-x64.zip for an Intel Mac. Double-click it to unzip, then drag ShinyForge.app into Applications.
  2. The first time, macOS says it can't check the app, because ShinyForge isn't from a registered Apple developer. Close the message, open System Settings → Privacy & Security, scroll down and click Open Anyway. You only do this once.
  3. Recording from a capture card asks for camera (and microphone) permission the first time. Allow it.
  4. Portable: ShinyForge-macOS-…-Portable.zip holds the app and a portable.flag. Keep them together, for example on a USB drive.

Linux

  1. Ubuntu, Debian, Mint and others: download shinyforge_…_amd64.deb and install it with the software installer, or with sudo apt install ./shinyforge_…_amd64.deb. ShinyForge appears in the app menu, and the shinyforge command starts it.
  2. Any distribution: unpack ShinyForge-Linux-x64-Portable.tar.gz and run ./ShinyForge in the ShinyForge Portable folder.
  3. For recording and the hunter: sudo apt install ffmpeg python3 python3-opencv python3-numpy python3-yaml, and python3 -m pip install mss.
  4. For the ESP32-S3 board (wireless trades), add yourself to the dialout group once (sudo usermod -aG dialout $USER), then log out and back in.

What's different on macOS and Linux

The same ShinyForge, with the same pages and features, plus these differences:

  • Pokédex tracker sync uses Microsoft Excel on Windows, which keeps the trackers' macros and pictures intact, so Sync is Windows-only. On macOS and Linux you can still find, download and open the trackers, and use the Pokédex window.
  • SysBot.exe (hunting in Let's Go, Sword/Shield and BD/SP), the PKHeX program, 3DS Capture and Streamlabs are Windows programs, so they're left out there. The FireRed/LeafGreen hunter, the 3DS bot, Checkpoint saves, saves and Game Info, wireless trades, statistics, alerts, overlay and remote all work.
  • Recording uses AVFoundation on macOS (capture cards, cameras and the screen) and V4L2 capture devices, the X11 screen and PulseAudio on Linux.
  • Keep the computer awake uses caffeinate on macOS and systemd-inhibit on Linux.
  • Updates: when a new version comes out, ShinyForge opens its release page, where you download the macOS or Linux build.

3 Quick start

  1. Open ShinyForge and pick Nintendo Switch or Nintendo 3DS. ShinyForge asks for the console's IP address (once per run, pre-filled with the last one). On the Switch it's under System Settings → Internet; on the 3DS, Rosalina shows it. Cancel still opens the games (recording, trackers and saves don't need the console online); anything that does need it asks again.
  2. If a yellow banner says programs are missing, click Review → Install all.
  3. Click your game. Its page has four cards: Shiny Hunt, Record Gameplay, Collection Tracker and Pokémon HOME folder + Game Info.
  4. For hunting, make sure your console is set up (see Switch & 3DS setup). Stand in front of the Pokémon, save in-game, then click Start hunting.
  5. Optional: open Settings and add a Discord webhook or ntfy topic so your phone buzzes when a shiny appears. Use Test notification to check it works.
TipClick Guide in the top bar any time to open this page.

5 Shiny hunting

The Shiny Hunt (automatic) card on a game's page offers the right bot for that game. Every bot does the same basic job: it plays the encounter over and over, checks every Pokémon, and stops all input when it finds a shiny so you can catch it.

Before every huntStand in front of the Pokémon (or in the grass or water) and save in-game. Soft resets go back to your last save.

Switch: FireRed / LeafGreen

Choose ShinyForge hunter (Python) (recommended) or SysBot.exe – FRLG_EncounterBot. Both use the same hunting logic.

  • Auto mode reads the game's memory to see where you are.
    • At a legendary or static spot (Deoxys, the legendary birds, Mewtwo, Lugia, Ho-Oh, Snorlax), it soft resets and goes straight from the title screen into the battle (tested: every reset gives a different Pokémon; a little random timing is added only if a repeat ever shows up).
    • Anywhere else, it walks for wild encounters and runs from ordinary Pokémon. It never runs from a legendary.
  • Every encounter is logged with its species, level, IVs, EVs, nature, Hidden Power, PID and shiny value. The log is used by Hunt statistics.
  • The game doesn't have to be open. If it isn't, ShinyForge offers to open it when you click Start hunting. The same happens if the FTP app or Homebrew Menu is still open. ShinyForge closes the FTP app, then finds FireRed / LeafGreen and starts it. It presses A through the title screen until your save is loaded, and the hunt starts from there. See how ShinyForge finds and opens the game. It never closes a game you're playing.
  • Use Pause / Resume to stop after the current attempt and carry on later. Stop Python hunter ends the hunt.
  • Hunter output, under the Shiny Hunt card, shows what the Python hunter is doing live, so no separate window opens on Windows. When it finds something, it stops pressing buttons and asks there: Keep hunting (this can reset the game, so catch and save first) or Stop hunter. Closing ShinyForge doesn't stop a running hunt, and its output is back when you open ShinyForge again.
  • Shiny failsafe. A find stays held until you press Keep hunting yourself. If the Switch falls asleep while it waits and you reconnect (even with a new IP address), ShinyForge never restarts the hunter on its own, so the game isn't reset. A hunter that gets started again while a find is held presses nothing until you answer. Start hunting asks first, because starting resets the game. Catch and save first.
  • The same Pokémon coming back (same PID) is fixed automatically and quietly: the hunter retries the reset or adds a little random timing. You're only told if it can't be fixed.
  • Hunt options sets stop rules, auto-catch and shiny RNG. Statistics opens this hunt's numbers.
Wild hunting tipLead with a Pokémon that's faster or higher level than the wild ones, or one holding a Smoke Ball. Failed escapes cost HP, and the bot stops if your lead faints.

How ShinyForge finds and opens the game on the Switch

  1. It puts the cursor on the first game of the HOME menu and checks that on a screenshot, so it always starts from the same place.
  2. It goes right along the HOME menu and compares each game with the official icon of the game you picked in ShinyForge (every language).
  3. If the game isn't there, it opens All Software at the end of the row and goes through every game you have, row by row.
  4. Nothing is started until the right game is selected. Then ShinyForge presses A.
  5. If the Switch asks "Who is using the software?", ShinyForge shows you that screen and asks which user should play. It selects that user and carries on. Cancel stops without starting anything.
  6. It checks the game that started (its title ID). For FireRed / LeafGreen it then loads your save.

ShinyForge works through sys-botbase and screenshots of the Switch, so don't touch the controller while it does this.

Switch: Let's Go, Sword/Shield, Brilliant Diamond/Shining Pearl

These games use SysBot.exe (Sys-EncounterBot.NET). ShinyForge writes your Switch's address into its settings and opens it with the right routine already selected. Press Start All in the SysBot window to begin.

  • Let's Go: LGPE_EncounterBot (stationary Pokémon, gifts, trades, GO Park).
  • Sword/Shield: SWSH_EncounterBot (resets, Pokémon in a line, the legendary dogs, Keldeo, Max Lair, eggs).
  • BD/SP: the BDSP_RNG tool.

Legends: Arceus, Scarlet/Violet and Legends: Z-A don't have a hunting bot yet. Recording, tracking and save export still work for them.

Nintendo 3DS: X/Y, Omega Ruby/Alpha Sapphire, Sun/Moon, Ultra Sun/Ultra Moon

ShinyForge controls your 3DS over WiFi through Luma3DS's Rosalina menu (see setup), so no extra hardware is needed.

  1. Click Test connection. Enter your 3DS's IP address if asked. ShinyForge should say which game is running and show your trainer name.
  2. Pick a Mode:
    • Auto soft resets for legendaries and walks for wild encounters.
    • Soft reset is for static and legendary Pokémon.
    • Wild encounters walks and runs from each battle.
  3. For walking, pick Left / Right or Up / Down, then click Start hunting. Every encounter appears in the log on the card.

Stop rules and Statistics work for 3DS hunts too.

Nintendo 3DS Virtual Console: Red, Blue, Yellow, Gold, Silver, Crystal

The Game Boy and Game Boy Color games from the 3DS eShop (English versions) work with the same 3DS hunt card.

  • Start the game on the 3DS and CONTINUE into your save, with at least one Pokémon in your party. Then click Test connection.
  • If the game isn't open, ShinyForge opens it for you. It presses A on the HOME Menu, which starts the selected game (the cursor stays on the game you played last) or goes back to a suspended one. Then it goes through the title screen and CONTINUE. So leave the HOME Menu cursor on the game's icon. If the wrong game would open, start it yourself.
  • The first time, ShinyForge searches the 3DS memory for the Game Boy's memory inside the Virtual Console emulator. This can take a minute. It recognises it by your party list, then reads the wild Pokémon's species, level and DVs from it (the addresses come from the pret disassemblies).
  • Soft resets use A + B + Start + Select. Running away picks RUN (bottom right of the battle menu).
  • Shiny means shiny the way Pokémon Bank sees it after Poké Transporter, which uses the Gold/Silver rule. Defense, Speed and Special DVs must all be 10, and Attack must be 2, 3, 6, 7, 10, 11, 14 or 15. Red, Blue and Yellow never show shinies in the game itself, but a Pokémon with those DVs comes out shiny in Bank.
Shiny after moving up to later gamesA game's Pokédex shows, for each Pokémon you own:
  • Gen 1 / Gen 2: its DVs, and whether it will be shiny in Pokémon Bank (the rule above).
  • Gen 3 - 5: a shiny stays shiny in every later game, because Pal Park, Poké Transfer and Pokémon Bank keep its PID. From Gen 6 on, the shiny limit is 16 instead of 8. But Pokémon Bank is reported to adjust Pokémon with a "shiny value" of 8 - 15 so they stay normal, so ShinyForge doesn't count those as shiny.
Other handheld gamesDS and GBA games run in a special compatibility mode on the 3DS where Luma3DS's WiFi tools aren't available, so they can't be hunted automatically. Recording, tracking and save export work for all of them.

6 Hunt options

Open Hunt options from the Shiny Hunt card. The 3DS calls this Stop rules. Your choices are saved and given to the bot the next time it starts. If the Python hunter is already running, it uses the new stop targets, rules, auto-catch and notification settings from its next encounter (no restart needed).

Each game only shows what its bot can really do:

  • Shiny RNG manipulation and auto-catch: FireRed / LeafGreen (Switch) only. 3DS games (X/Y, ORAS, Sun/Moon, Ultra Sun/Moon) don't show them.
  • Nature and IV rules: Gen 3 and newer. Gen 1/2 Virtual Console games have no natures and use DVs (0–15), so they only have stop targets. Gen 1 also has no genders.
  • SysBot.exe games: stop targets only (SysBot has its own other settings).
  • Find in Checkpoint: not on GBA games, which Checkpoint can't back up.

Stop targets

Each game has its own list of stop targets: "stop when THIS Pokémon shows up". Pick any Pokémon you can get in that game (type its name or number), then:

  • Form: any form, or one (Alolan, Galarian, an Unown letter...).
  • Gender: any, male or female.
  • Shiny: shiny or not, shiny only, not shiny; in Sword/Shield also star or square shiny.

The list only offers Pokémon you can really get in that game (from PKHeX's game data; event gifts aren't counted, since a bot can't hunt them). If you ask for one that can't exist, ShinyForge says so and doesn't add it, e.g. a male Chansey (always female), a female Magnemite (genderless), or a shiny Zacian in Sword (shiny-locked). The bot still stops on every shiny on top of your targets.

  • FireRed / LeafGreen (Python hunter) and 3DS games: all targets are checked. Open Hunt options / Stop rules.
  • SysBot.exe games (Let's Go, Sword/Shield, BD/SP): Stop targets on the Shiny Hunt card. SysBot holds one target, so it uses the first in the list. Gender needs the TargetGender condition added to the self-built Sys-EncounterBot.

Stop on more than shinies

The bot always stops on a shiny. It can also stop on any of these:

  • Stop targets (above).
  • Natures: tick the ones you want, e.g. Adamant or Timid.
  • Minimum IV total (out of 186), and/or minimum IVs per stat.
  • Require all: when ticked, every rule you set must match. When it's off, any one rule is enough.

Auto-catch off by default

When it finds a shiny (or a stop-rule match), the bot can throw balls for you (FireRed/LeafGreen Python hunter).

  • Off: the bot stops and leaves the battle to you.
  • Non-legendary only or Everything.
  • Ball to throw: pick the ball by name (Master, Ultra, Great, Poké, Net, Nest, Repeat, Timer, Luxury, Premier, Dive, Safari).
  • Max balls: stops trying after this many throws (or when that ball runs out).

The hunter reads your Poké Balls pocket from the game to find where the ball is, then picks it in the battle bag one step at a time, checking every step on a screenshot. If a step doesn't work (a lost button press), it throws nothing and leaves the battle to you. If the ball isn't in your bag, it warns you when the hunt starts.

Save after a catchAfter a successful catch, the bot stops and reminds you to save the game yourself. It never saves during a hunt.

Shiny RNG manipulation off by default

FireRed/LeafGreen on the Switch only. Instead of resetting over and over, the hunter reads the game's random number generator live and times its A press so the Pokémon should be shiny.

  • Works for static encounters: Deoxys, Mewtwo, the birds, Lugia, Ho-Oh and Snorlax.
  • Turning it on asks you to confirm first. It's always your choice.
  • You can also ask for natures and minimum IVs. The more you ask for, the longer it takes to find a matching frame.
  • A press can land a frame or two off. That's normal: the bot adjusts its timing and tries again.
Fair playRNG manipulation is a well-known technique, but some communities and events don't accept RNG'd Pokémon. That's why ShinyForge never uses it unless you turn it on.

7 Recording & shiny clips

Record Gameplay

Records your game continuously in numbered files (Recording_0001.mp4, Recording_0002.mp4…) with no gap between them. Long hunts stay in easy-to-handle pieces.

  • Video:
    • DS and 3DS games (Gen 4–7): 3DS Capture – Top + Bottom (stacked) records both screens, top above bottom like a real DS/3DS.
    • Game Boy, Game Boy Color and Game Boy Advance games (Gen 1–3): the 3DS Capture – Top window (they only use one screen).
    • Switch games (Gen 8–9, Let's Go and the Switch FireRed/LeafGreen): your capture card (e.g. "Game Capture") or the Streamlabs Desktop window.
  • Audio is picked for you: 3DS games record the sound 3DS Capture plays (it arrives over the USB cable), Switch games the capture card's own audio device. You can still choose another device or no audio.
  • Frame: puts the recording (and shiny clips) inside a picture of the console so it looks like a real console. Automatic (the default) always uses the console the game belongs to: Game Boy, Game Boy Color, Game Boy Advance, DS or 3DS, and for Switch games the Switch 2 picture when the video comes from the Switch 2 capture card ("USB Video") and the Switch 1 picture otherwise. You can also pick a frame yourself or choose No frame. The game picture is fitted exactly into the console's screen(s). If you record the Streamlabs Desktop window instead, ShinyForge opens Streamlabs, switches it to the console's scene (made with the Streamlabs scenes button) and adds no second frame. The PNGs live in Desktop\Console Frames if you have that folder, otherwise in Documents\ShinyForge\Console Frames (portable: Console Frames next to ShinyForge.exe); Settings can point somewhere else. A screen_positions.json there tells ShinyForge where each screen is. Missing pictures are downloaded from ShinyForge's GitHub page automatically when you start recording or make the Streamlabs scenes (pictures you already have are never replaced).
  • Cut the black border (DS and Game Boy games): 3DS Capture shows these games with black bars inside the 3DS screen; this keeps only the game picture.
  • 3DS Capture's screen windows must not be minimized (a minimized window shows nothing). ShinyForge brings them back by itself when a recording starts.
  • Streamlabs scenes: with Streamlabs Desktop open (ShinyForge offers to start it), this button makes one scene per console — Game Boy, Game Boy Color, Game Boy Advance, Nintendo DS, 3DS, Switch 1 and Switch 2 — with the game fitted into the console picture, the same way as the recordings. Scenes that already have a console's name are updated instead of copied, your existing capture sources are reused, and the Switch capture devices are chosen in the window. With Dual Output, the vertical canvas is laid out too. Missing console pictures are downloaded first, and afterwards every scene is checked: each game window must fill its console screen exactly (a scene that doesn't fit is laid out again), and the result is listed per scene. Starting a recording also makes the console's scene by itself when Streamlabs doesn't have it yet.
  • Segment length: 5–30 minutes per file.
  • Folder: where the files go. A new recording carries on the numbering.
  • On 3DS game pages, Open 3DS Capture launches the capture program.
  • You stay in control. Recording never touches your console: it doesn't open, close or press anything in the game. You play, ShinyForge records.
  • Start recording opens Streamlabs Desktop (if it isn't open yet) and switches it to the game's console scene, then records. A few seconds later the card shows the file being written (● Recording into Recording_0001.mp4). If nothing is written, ShinyForge stops and tells you why.

Shiny clips on by default

While the Switch hunter runs, ShinyForge keeps the last minute of video in a rolling buffer. When a shiny appears, it waits a few more seconds and saves Shiny_<Pokémon>_<date>.mp4 (a stop target that isn't shiny: Found_<Pokémon>_<date>.mp4). The clip goes to Shiny Clips in the game's recording folder, or to Data\Shiny Clips.

  • Uses the capture source chosen on the Record Gameplay card.
  • The Shiny clips button on the Shiny Hunt card opens the folder the clips are saved in.
  • Change the length (20–300 seconds) or turn it off in Settings → Shiny clips.
  • It pauses while a full recording is running, since that recording already has the moment.

The hunter also saves a screenshot of the find: straight from the Switch with the original sys-botbase (so you get a picture even without a capture card), from the capture card with sys-botbase-cpp.

8 Pokédex tracker

The Collection Tracker → Pokédex spreadsheet card keeps your Excel Pokédex tracker up to date.

  • Auto-recognize finds the right tracker for this game. Your bundled spreadsheets are in a folder named like Gen 3\(10) Fire Red\…. You can also pick one with Choose spreadsheet, or open it with Open.
  • Save file: ShinyForge finds your save automatically, or you can choose one. For FireRed/LeafGreen on the Switch, it can also read your party and boxes live from the Switch.
  • Sync now marks In Box, OT (caught by you) and Shiny as Y for every Pokémon you own.
    • It only ever adds a Y. It never removes your own ticks.
    • Your spreadsheet is backed up first.
  • Start over (reset tracker): for when you start the game over. After you confirm, it turns off automatic monitoring for the game, forgets the save file chosen for the tracker (the newest save is found automatically again), and sets every In Box, OT and Shiny mark back to N in the game's tracker spreadsheet(s). Each spreadsheet is backed up first, so the Backups window can bring your old progress back. N/A cells and other columns aren't touched.

No tracker for this game yet (portable copy, or the download was skipped during installation)? Click Download tracker. ShinyForge downloads just that game's tracker from its GitHub page into the Spreadsheets folder, checks it, and never overwrites a tracker you already have.

Excel neededSyncing uses Microsoft Excel in the background, so Excel must be installed. Close the tracker in Excel before syncing.

Pokédex window (pop-out)

Click Pokédex (pop-out) for a full Pokédex of the game in its own window.

  • Uses that game's own sprites: Game Boy sprites for Red/Blue, Emerald sprites for Emerald, and so on.
  • Pokémon you own are shown in colour. Missing ones appear as silhouettes.
  • Includes forms, regional variants and visible female differences, where the game has them.
  • Click a Pokémon for its info panel: types, where to find it in this game, how it evolves, and links to Bulbapedia and Serebii.
  • Evolution shows the whole family, one line per branch, with the Pokémon you clicked in [brackets]. For example: Pidgey at Lv. 18 > [Pidgeotto] at Lv. 36 > Pidgeot, or Eevee with high friendship at night (level up) > Umbreon. Every method is written out: level, item, friendship, trade (and the held item), known move, time of day, a place in that game (for example Magnezone: Mt. Coronet in Platinum), party members, gender and more. Evolutions a game can't do are marked, such as Espeon and Umbreon in FireRed/LeafGreen, which have no clock.
  • The Serebii link opens Serebii's Pokédex for that game's generation, for example the Gen 3 page with the FireRed/LeafGreen data when you're in LeafGreen. Let's Go uses the Sun/Moon Pokédex, Brilliant Diamond/Shining Pearl and Legends: Arceus the Sword/Shield one, and Legends: Z-A the Scarlet/Violet one, because that's where Serebii keeps them.

9 Saves, HOME folder & Game Info

The Pokémon HOME folder + Game Info card works with your exported save files.

  1. Browse to the folder where this game's save files are kept (e.g. backups from Checkpoint or JKSV), then click Find save. Sub-folders are searched too.
  2. Export Pokémon + Game Info writes every Pokémon in the save to its own file. They're sorted into a folder you can use with Pokémon HOME transfer tools and PKHeX.
  3. View Game Info shows a readable report:
    • Trainer name and IDs, play time and money.
    • Pokédex counts, party, box totals and every shiny.
  4. Open in PKHeX opens the save in PKHeX, if it's installed.

ShinyForge reads saves from every main-series game from Red/Blue to Legends: Z-A, using PKHeX's core library. It only reads them and never writes to them.

Saves from Checkpoint (SD card)

If you back up your saves with Checkpoint on the console, ShinyForge can find them on the SD card. Click Find in Checkpoint, then choose where the card is:

  • Inside the console, over WiFi (no need to take the card out):
    • Switch: ShinyForge starts the FTP app for you (through sys-botbase):
      1. If a game is open, ShinyForge asks you to save and close it (HOME, then X on the game, then Close) and waits for your OK. It checks that the game really is closed before it continues.
      2. It starts a game from the HOME menu while holding R, so Atmosphère opens the Homebrew Menu instead of the game. If the Switch asks "Who is using the software?", it picks the first user while still holding R.
      3. It steps through the Homebrew Menu, recognises ftpd or Checkpoint by its icon, and starts it. ftpd comes first because it always serves FTP. Checkpoint's FTP server only runs when it's turned on in Checkpoint's settings.
      4. Don't touch the controller while this runs (about a minute).
      5. When ShinyForge has finished with the SD card, it offers to go back to the game. It closes the FTP app, then finds and opens the game you're working on (see how ShinyForge finds and opens the game). For FireRed / LeafGreen it also loads your save and starts the shiny hunt. Choose No to close the FTP app yourself (HOME, X, Close).
    • 3DS: ShinyForge asks you to save and exit the game and open Checkpoint (with its FTP server turned on) or ftpd, then click OK.
    • You can also start the FTP app yourself: Checkpoint's FTP server shows FTP server running on <IP>:50000, ftpd uses port 5000.
    ShinyForge uses the console's IP address (the one you entered for the Switch or 3DS) and downloads only this game's Checkpoint backups. It only reads: it lists folders and downloads files, and never changes anything on the console. The downloaded backups are kept in a Console SD folder next to ShinyForge's settings, and unchanged files aren't downloaded again.
  • In this PC: it searches every drive for Checkpoint's folders:
    • 3DS: sdmc:/3ds/Checkpoint/saves/0x<unique ID> <game title>/ (DS cartridges: <game code> <cartridge title>, e.g. IRBO POKEMON B)
    • Switch: sdmc:/switch/Checkpoint/saves/0x<title ID> 0x<title ID>/ (Checkpoint repeats the ID instead of names with "é")
    If you copied the SD card to the PC, choose that folder when asked. It's remembered in Settings.
  • The game you opened is matched by its title ID (e.g. 0x01B51 for Ultra Moon, 0x0100ABF008968000 for Sword), its game code for DS cartridges, or its name for the Game Boy games (Virtual Console).
  • When several backups are found, you choose which one to use. The newest is selected.
  • The chosen backup is copied to this PC (Documents\ShinyForge\Saves\<game>, or Saves next to the portable program). The HOME folder, Game Info and the Pokédex tracker then use that copy.
You make the backupsBefore the first scan, ShinyForge reminds you to save in-game and back up the save yourself with Checkpoint. ShinyForge can't make Checkpoint backups, and it never writes to your SD card. When you scan again later, it asks whether you'd like to make a fresh backup first and shows the steps.

10 Wireless trades & Mystery Gift

On every Switch game's page, Wireless trades (pokeldn) opens trading and Mystery Gift over the console's local wireless. This uses pokeldn by Decryptu: a small board acts as the radio, and nothing is installed on the console. It works with FireRed/LeafGreen, Let's Go, Sword/Shield, BD/SP, Legends: Arceus, Scarlet/Violet and Legends: Z-A.

You need an ESP32-S3 boardAn ESP32-S3 is a small, inexpensive microcontroller board, for example the Seeed XIAO ESP32S3 or an ESP32-S3 DevKit. Connect it with a USB data cable (charge-only cables don't work) to the board's native USB socket. You also need the prod.keys dumped from your own Switch.

First time

  1. ShinyForge asks whether you have an ESP32-S3. If you don't, it shows pokeldn's list of supported boards and stops there.
  2. It checks that the board is plugged in, which pokeldn firmware it runs, and whether the pokeldn app and esptool are installed and up to date.
  3. If anything is missing or old, it lists what it would do and asks first. Then it downloads from the official GitHub releases, checks every file against its published SHA-256 checksum, installs, and writes the radio firmware to the board with Espressif's esptool.
  4. Finally it asks where prod.keys is on this PC. Only the location is stored, in ShinyForge and in pokeldn's own settings. The file is never copied, uploaded or shown.

After that

  • The window shows a checklist: board, firmware, pokeldn app, firmware file, esptool and prod.keys. Use Install / update everything, Install firmware on the board, Choose prod.keys… or Check again.
  • Open pokeldn starts it. Choose a game and a tool there, then follow the steps it shows for the console.
  • New pokeldn versions show up in Tools & Updates.

For the portable version, pokeldn, esptool and the ESP32-S3 firmware can also sit in the Backup Tools folder. ShinyForge uses them from there.

11 Living Dex planner

Click Living Dex in the top bar. ShinyForge reads the saves you've set up for every game and builds one list of every Pokémon you can put in a Pokémon HOME box, in HOME's box order with Pokémon HOME's own pictures:

  • 1,391 slots: all 1,025 species plus every boxable form. That covers regional forms (Alolan, Galarian, Hisuian, Paldean), visible female differences, Unown letters, Vivillon patterns, cap Pikachu, every Alcremie cream and sweet, Minior cores and more. The list follows Serebii's Pokémon HOME depositable Pokémon list and was checked slot by slot. Mega Evolutions, Gigantamax and other battle-only forms aren't included because they can't be put in a box.
  • A slot counts as owned only when the Pokémon matches it exactly: its form, its male or female look where those differ, and its Alcremie sweet. You can see which slots you own, in which game and where in that save.
  • Shiny ones show their shiny HOME picture and a ★.
  • In these games lists the games that have that exact form (for example Alolan Vulpix only from Sun/Moon on). Where to find it in a game (its locations) is shown in that game's own Pokédex, not in the Living Dex.
  • Turn off Forms & genders to see one slot per species (1,025) instead.

Click Rescan saves after you've played or added a new save.

12 Hunt statistics

Open Hunt stats from the top bar, or Statistics on a hunt card. Pick a hunt log at the top.

  • Encounters in the current hunt, counted since your last shiny.
  • Shiny odds: 1 in 8,192 up to Gen 5 and 1 in 4,096 from Gen 6. Tick Shiny Charm if you have it (Gen 5 and later).
  • Chance you'd have found one by now, plus how many encounters it takes for 50% and 90% of hunters to find one.
  • Speed (encounters per hour) and time to 90%.
  • Best IVs this hunt, the last encounter, most common natures, species seen and shinies found.
  • A 24-hour chart of encounters per hour, which makes it easy to spot when a hunt stopped.

The window refreshes itself every 10 seconds. Open log opens the raw CSV file.

15 Safety features

System check (every minute)

Checks that everything running still works: hunts, recordings, clip buffer, console connections, disk space and data folders. Problems show in the status bar and a banner, and go to your phone if you set that up. Click the status-bar light for details, Check now or Open log.

Same-Pokémon guard

If the hunter sees exactly the same Pokémon twice in a row, the reset didn't register. It warns you, holds the reset buttons longer and checks that the game really restarted. If it happens 3 times in a row, ShinyForge restarts the hunter automatically (up to 3 times), then stops and tells you.

Console address changed?

Before a hunt starts, and whenever a running hunt loses contact for several minutes, ShinyForge checks that the Switch or 3DS still answers. If it doesn't, it asks for the new IP address and carries on.

Keep the PC awake

While a hunt or recording runs, Windows won't go to sleep (the screen can still turn off). If the PC sleeps anyway, for example when a laptop lid is closed, you'll be told.

Diagnose & fix

Select a problem in the system check to see what ShinyForge thinks went wrong and step-by-step solutions. When it can fix the problem itself (restart a hunt, test the Switch / 3DS connection, repair the data folder, move the overlay to a free port, trim its logs), click the fix button.

Minor problems stay quiet

Problems that don't affect hunting or playing (stream overlay, shiny clips, recordings, collection tracker, backups, small background hiccups) don't pop up or make a sound. They're written to issues.log in the data folder. Tick Show minor issues to see them.

Report to GitHub

If the fix didn't help, Report to GitHub opens a filled-in bug report for ShinyForge in your browser. It contains the problem, the diagnosis, the fix result, your version and the end of the log. Your user name, PC name, folders and IP / e-mail addresses are removed first. Nothing is sent until you press Create on GitHub (a free account is needed).

Automatic backups

Before ShinyForge updates a spreadsheet or exports a save, it backs up the file (only if it changed). It keeps 20 save backups and 3 spreadsheet backups by default. Restore any of them from Settings → Backups…, which first backs up the current file too.

Nothing risky by default

RNG manipulation and auto-catch are off until you turn them on. Saves are only read, and the bot never saves your game.

16 Tools & updates

Tools & Updates lists every helper program, whether it was found, where, and which version you have (shown next to its name a moment after the window opens).

SysBot must be up to dateBefore a hunt or a tool starts (recording, sys-botbase, Pokémon Automation, PKHeX, wireless trades, the Checkpoint save reader), ShinyForge checks that SysBot.exe is on its latest release. If it isn't, it asks you to update first: Yes updates it (or, for a copy you built yourself, opens the download page to rebuild), No carries on this time, Cancel stops.
  • Install all updates installs every update ShinyForge can install itself, one after the other, and then lists what happened to each. Updates that need you (such as a SysBot you built yourself) are listed instead.
  • Install or Install all missing downloads programs from their official sources where that's allowed. PKHeX is only offered on Project Pokémon's site, so that page opens for you instead.
  • Check for updates compares your versions with the latest ones. It runs at every start and again every hour while ShinyForge is open, and Tools & Updates checks again by itself when its last answer is more than 10 minutes old (turn the automatic checks on or off in Settings → Updates). A new update shows a banner once. If a tool can't be checked (offline), the window says which one. What it checks:
    • ShinyForge itself, and the PKHeX library inside it.
    • FFmpeg, Streamlabs Desktop, Python: winget on Windows (one-click update), Homebrew on macOS (one-click), apt on Linux (shows the command, since it needs your password).
    • PKHeX, pokeldn and esptool: against their latest releases, with one-click updates (pokeldn and esptool also when Wireless trades isn't set up).
    • 3DS Capture: against the download on 3dscapture.com. The update unzips the new version next to the old one (which is kept) and ShinyForge uses it.
    • SysBot.exe: a copy ShinyForge downloaded updates with one click. A copy you built from source (with your own routines, such as FRLG) is only reported, because the download wouldn't have your routines.
    • Pokémon Automation: its version comes from the unzipped folder. The update opens their download page; unzip the new version next to the old one and ShinyForge uses the newest.
    • sys-botbase on the Switch, when the Switch answers and no hunt is running: the original against olliz0r's latest release, sys-botbase-cpp against Pokémon Automation's.
    Each row says what the check found: Up to date with the newest version it compared against, Update available, or why it couldn't check. Microsoft Excel publishes no version to compare with; it's updated by Office itself (in Excel: File → Account → Update Options → Update Now).

Updating ShinyForge

Versions are numbered 1.X.Z, shown at the bottom-right of the window, e.g. v1.0.15. X goes up for big updates; Z goes up for patches and small fixes (it starts again at 0 after a big update). So 1.1.0 is newer than 1.0.20.

  • When ShinyForge starts, it checks the ShinyForge GitHub page for a newer release. If there is one, a window shows what's new with these options:
    • Download and install: downloads only the program files (about 150 MB, not the multi-GB installer). ShinyForge closes, the new files replace the old ones, and it starts again. This works the same for installed and portable copies. Your settings, spreadsheets, Checkpoint copies, Backup Tools and the hunter's config.yaml are kept. New spreadsheets that come with a release are in the full installer.
    • View on GitHub: opens the release page.
    • Skip this version or Later.
  • Check any time in Tools & Updates: the top row shows your version and build, with a Check now button.
  • Turn the automatic check off in Settings → Updates.

The Backup Tools folder

If a program isn't installed on the PC, ShinyForge also looks in the Backup Tools folder (sub-folders too). Copy FFmpeg, PKHeX, SysBot, 3DS Capture or a portable Python into it, and ShinyForge finds them on any PC. This is handy for the portable version on a USB drive.

Settings also has Create portable copy…, which makes a portable ShinyForge with your settings, ready to take to another PC.

17 Switch & 3DS setup

Homebrew noticeAutomatic hunting needs custom firmware on your console. Only use it on hardware you own, keep a backup of your saves, and play offline when using homebrew.

Nintendo Switch (sys-botbase)

  1. Your Switch needs to be running Atmosphère custom firmware.
  2. Download sys-botbase from its official page, github.com/olliz0r/sys-botbase/releases. Copy its atmosphere folder to the root of your SD card, which puts it in atmosphere/contents/430000000000000B/. Then reboot.
  3. On the Switch, find its IP address in System Settings → Internet.
  4. Enter the address in ShinyForge under Settings → Switch IP address (port 6000). If you start a hunt without it, ShinyForge asks for it.
  5. Keep the Switch and PC on the same network. Turn off the Switch's sleep mode while hunting.

Optional: sys-botbase-cpp

Screenshots come from your capture cardsys-botbase-cpp has only 3 MB of memory: once a game or the Homebrew Menu runs, a screenshot asked from it doesn't fit, and it stops answering until the Switch restarts (its log says "std::bad_alloc in pixelPeek"). So with sys-botbase-cpp, ShinyForge and its hunter take every screenshot from the capture card your Switch is docked to (the card your Switch games record from, else an Elgato card; Settings → Switch can name it). The sys-botbase window says which card it uses. Without a capture card, ShinyForge can't open games, find the FTP app or save with sys-botbase-cpp. Use the original sys-botbase then (Restore previous sys-botbase). Older ShinyForge versions and some other bots still ask sys-botbase-cpp for screenshots; if it stops answering, restart the Switch.

Pokémon Automation's sys-botbase-cpp (github.com/PokemonAutomation/sys-botbase-cpp, GPL-3.0) is a rewrite of sys-botbase with the same commands. It uses less memory, fixes a bug that could randomly crash the Switch, times button presses exactly, writes a log file to atmosphere/contents/430000000000000B/log.txt, and can talk over a USB cable. On any Switch game page, Shiny Hunt card → sys-botbase shows which version your Switch runs. Its Install sys-botbase-cpp button downloads the latest release from GitHub, starts the FTP app, backs up your current sys-botbase into Data\Backups and copies the new one onto the SD card. Close your game first, then restart the Switch when it's done.

WiFi or USB

  • WiFi (default): the Switch stays docked, so recording, shiny clips and the Python hunter all work.
  • USB (Windows, sys-botbase-cpp): sys-botbase → Use USB, restart the Switch, take it out of the dock and plug it into the PC with a USB-C cable. The first time, install the WinUSB driver for "Nintendo Switch" (057E 3000) with Zadig. USB doesn't depend on WiFi, but there's no capture card picture without the dock, so recording is off, and the Python hunter and SysBot.exe need WiFi. sys-botbase listens on one of the two at a time. If only the other one answers (before the restart, say), ShinyForge switches to it by itself.
  • If the Switch keeps dropping off the network (Switch error 2124-4508), that's its WiFi connection: move it closer to the router or use a wired LAN adapter in the dock.

Unmodified Switch: Pokémon Automation

Pokémon Automation's Computer Control has tested programs for every Switch Pokémon game (shiny hunts, eggs, raids, auto-saving). It runs on an unmodified Switch through a microcontroller acting as a controller (ESP32-S3, Raspberry Pi Pico W and others, flashed with their firmware) plus your capture card, or on a modded Switch through sys-botbase. ShinyForge doesn't include any of it. Download it from their GitHub and unzip it into Downloads, Desktop or Documents (not OneDrive). The Pokémon Automation button on each Switch game page then starts it and opens that game's program list. Pokémon HOME has its own tile at the end of the Switch games with only this button, for their Box Sorter, Box Sorter Living Dex and Page Swap programs. An ESP32-S3 can't run pokeldn and Pokémon Automation's firmware at the same time. Their programs are for personal, non-profit use. Ask their Discord admins about anything else.

Nintendo 3DS (Luma3DS / Rosalina)

  1. Your 3DS needs Luma3DS custom firmware, on the same WiFi as your PC.
  2. Start the game and load your save.
  3. Open the Rosalina menu with L + D-Pad Down + Select.
    • Turn on InputRedirection.
    • Open Debugger options → Enable debugger.
  4. Find the 3DS's IP address (Rosalina shows it). Enter it when ShinyForge asks, then click Test connection.

For recording, use a 3DS with a capture board and the 3DS Capture program, or any capture card that shows up on your PC.

18 The Python bot (advanced)

The FireRed/LeafGreen hunter is a Python program that ships with ShinyForge, in the PythonBot folder next to ShinyForge.exe. You can point Settings → Python hunting bot folder at another copy. ShinyForge starts it, passes your settings to it, and watches it for you, so most people never need to touch it. If you're curious:

  • config.yaml holds the bot's own settings: controller type and address, hunting mode, timings and detection thresholds. ShinyForge keeps the Switch address in it up to date.
  • shinyforge.json is written by ShinyForge with your Hunt options and alert settings. The bot reads it when it starts.
  • encounters.csv is the encounter log, and stats.json is the running counter.
  • start_hunt.bat starts the bot without ShinyForge.

Command line

python -m shinybot hunt            start hunting
python -m shinybot press A         send a button press to the Switch (test the connection)
python -m shinybot calibrate       set-up for the screen-based "vision" mode
python -m shinybot cameras         list capture cameras (vision mode)
python -m shinybot snapshot        save one captured frame
python -m shinybot test IMG...     run the shiny detector on screenshots

Hunting modes (hunt: mode in config.yaml)

  • auto (default) picks static or wild by where you're standing.
  • static, wild or fishing force one behaviour.
  • rng is the shiny RNG mode. Turn it on in Hunt options rather than here.
  • vision is the original screen-watching Deoxys bot. It uses a capture card instead of reading memory.

Instead of sys-botbase, the bot can also use a Raspberry Pi as a wireless Pro Controller (NXBT) for an unmodified Switch. Copy bridge/nxbt_bridge.py to the Pi, then set controller: type: nxbt. Memory reading needs sys-botbase, so this works with vision mode. The bot's README.md has the details.
